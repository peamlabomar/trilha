# Guia da Trilha Ecológica do Estuário do Rio Pacoti

Guia educacional para celular da Trilha Ecológica do PEAM (Programa de Educação Ambiental Marinha, LABOMAR/UFC), no CEAC, APA do Rio Pacoti, Eusébio (CE).

- Texto e projeto original: Erick Souza da Rocha
- Coordenação e revisão técnica: Ravena Sthefany Alves Nogueira
- Realização: PEAM · LABOMAR · UFC

O site funciona sem internet depois do primeiro acesso e pode ser instalado na tela inicial do celular.
